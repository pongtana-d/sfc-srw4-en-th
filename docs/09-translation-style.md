# 9. แนวการแปลที่ตกลงไว้แล้ว

## ขอบเขตการแปล

แพตช์นี้สร้างและทดสอบบน ROM English (EN) เท่านั้น ข้อความ โครงสร้าง และข้อจำกัดของ
ROM EN จึงเป็นฐานของงานแปลไทย

`script.source.json` และ `lookup` ที่มีภาษาญี่ปุ่นเป็นบทพูดที่ถอดไว้เพื่อช่วยยืนยัน
บริบทและความหมายเท่านั้น ไม่ใช่กฎการแปล ไม่ใช่คำแปลมาตรฐาน และห้ามใช้แทนข้อความ EN
เมื่อตัดสินคำไทย ให้ยึดข้อความ EN และ catalog/`glossary.th.json` ที่อนุมัติแล้วก่อน

ข้อความที่ใช้ macro ชื่อตัวเอก เช่น `<FB:1E80>` ต้องใช้ถ้อยคำไทยไม่ระบุเพศ เว้นแต่
route หรือข้อความต้นทางระบุเพศของผู้พูดชัดเจน

ไฟล์อ้างอิงหลักตอนแปลบทสนทนา:
`data/translations/references/dialogue.th.json`

ไฟล์นี้สร้างจาก catalog ชื่อนักบิน ชื่อสั้น ยูนิต อาวุธ ซีรีส์ ภูมิประเทศ และ
`glossary.th.json` ด้วย `python3 tools/build_dialogue_reference.py` ห้ามแก้ไฟล์ generated
โดยตรง ส่วน `rom-glossary.th.json` เป็น override สำหรับช่อง ROM ที่แคบ ไม่ใช่ศัพท์หลัก

ก่อนและหลังแก้ชื่อหรือศัพท์ในบทสนทนา ให้รัน:

```bash
python3 tools/build_dialogue_reference.py
python3 tools/audit_dialogue_reference.py --limit 10000 --samples 3
```

ต้องให้ `_meta.conflicts` ใน reference เป็น `0` และตรวจรายงาน audit ทีละกลุ่มตามบริบท
ของข้อความ EN ห้ามแก้ `references/dialogue.th.json` โดยตรงหรือ bulk replace
ภาษาญี่ปุ่นใช้ตรวจสอบความหมายได้เฉพาะเมื่อข้อความ EN ยังไม่ชัดเจน

## ชื่อคน ชื่อหุ่น

- **ชื่อสั้นต้องยึดรูป canonical ใน catalog** เพราะเป็นชื่อเล่น ไม่ใช่ตัวย่อของชื่อเต็ม
  เช่น `เรียว` ไม่ใช่ `เรียวมะ` แม้ชื่อเต็มจะเป็น `เรียวมะ นางาเระ`; `คริส` ไม่ใช่
  `คริสตินา`; `โมริโมริ` ไม่เติมตำแหน่ง; และ `ผบ.มิวะ` ใช้รูปย่อที่อนุมัติแล้ว
- **การสะกดชื่อเดียวกันต้องตรงกันทุกจอ** ถ้าชื่อเต็มสะกดแบบสากลไว้แล้ว ชื่อสั้นต้องตาม
  (เช่น โฟร์, คีธ, เบิร์นนิง และสไตเนอร์)
- ชื่อตะวันตกใช้การสะกดสากล ไม่ใช่คำอ่านแบบญี่ปุ่น: เลเปรอคอน, มินอฟสกี, โชบัม,
  อะโพจี

## ยศทหาร

- แปลยศให้สอดคล้องกับบริบทกองทัพในอนิเมะกันดั้ม ไม่ใช้ชื่อยศเฉพาะเหล่าทัพไทย
  เมื่อข้อความต้นฉบับไม่ได้ระบุเหล่าทัพ เช่น `少尉` = `ร้อยตรี`, `少佐` = `พันตรี`,
  `中将` = `พลโท`
- ทุกครั้งที่พบยศญี่ปุ่นใหม่ ให้ตรวจบริบทและบันทึกรูป canonical ไว้ในหมวด `ranks`
  ของ `data/translations/glossary.th.json` ก่อนใช้ และต้องใช้รูปนั้นให้ตรงกัน
- ห้าม bulk replace ยศโดยไม่ตรวจผู้พูด ต้นสังกัด และบริบทของแต่ละข้อความ

## ศัพท์เมนู

- ในป้ายเมนูที่ยังเป็นช่องแคบใช้อังกฤษสั้นตามที่เกมเดิมทำอยู่แล้ว: `LV`, `HP`,
  `EN`, `WILL`, `EXP`
- Unit command menu ใช้กรอบ P7 ที่ขยายได้ จึงแปลเป็นไทยเต็มคำ:
  `Move` = `เคลื่อนที่`, `Attack` = `โจมตี`, `Repair` = `ซ่อม`,
  `Transform` = `แปลงร่าง`, `Combine` = `รวมร่าง`, `Separate` = `แยกร่าง`,
  `Spirit` = `สปิริต`, `Supply` = `เติมเสบียง`, `Burrow` = `ใต้ดิน`,
  `Dive` = `ใต้น้ำ`, `Land` = `พื้นดิน`, `Fly` = `ขึ้นบิน`,
  `Status` = `สถานะ`, `Wait` = `รอ`, `Parts` = `ชิ้นส่วน`
- ในเนื้อความปกติใช้คำไทย เช่น `เลเวล` — ป้ายกับเนื้อความไม่ต้องใช้คำเดียวกัน
- ค่า CONFIG/หน้า OPTION ใช้อังกฤษของเกม (`ON`/`OFF`/`MONO`/`STEREO`/`SELECT`)
- คำสั่งเวลาถูกโจมตี: `反撃` = สวน/สวนกลับ, `回避` = หลบ, `防御` = กัน/ป้องกัน

## พลังจิต

ป้ายคำสั่ง `Spirit` ใน Unit command menu ใช้คำทับศัพท์ `สปิริต` ส่วนชื่อหมวด
กลไก ค่า SP และชื่อพลังแต่ละชนิดยังใช้ `พลังจิต` ตามบริบทเดิม

ชื่อพลังจิตแปลไว้ครบ 30 ชื่อพร้อมคำอธิบายและค่า SP ใน `spirit-descriptions.th.json`
(เช่น ฮึดสู้, อึดสุด, เฉียบ และสมาธิ)
ตัวอักษรย่อหนึ่งตัวของพลังจิตอยู่ใน catalog 13 ต้องให้สอดคล้องกับชื่อเต็ม

## สิ่งที่ตกลงว่าคงข้อความเดิมไว้

- ชื่อเพลง BGM และเนื้อเพลง (ตามคำขอของผู้ใช้)
- โลโก้/เครดิตที่เป็นภาพ
