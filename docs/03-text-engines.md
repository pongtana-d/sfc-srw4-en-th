# 3. เครื่องยนต์ข้อความของเกม

สถานะเอกสาร: นี่คือหลักฐาน contract ของ stock ordinary/story engine ที่ reverse ไว้
เป้าหมายใหม่ใน PLAN.md ใช้ layout/blitter core เดียวและให้ adapter รับผิดชอบเฉพาะ entry/exit
เกมมีเครื่องยนต์ข้อความ **สองตัว** ที่ใช้ตัวจำแนกฟอนต์ (classifier) ร่วมกัน
แต่มีสัญญาเรื่อง cursor คนละแบบ — นี่คือสาเหตุของบั๊กการวาดเกือบทั้งหมดที่เคยเจอ

| | เมนู/ทั่วไป (ordinary) | เนื้อเรื่อง/ฉากต่อสู้ (story) |
|---|---|---|
| cursor | `$18` เป็น cursor จริง | cursor อยู่ที่ `$0E2A`, `$18` กลับมาเท่าเดิมทุกครั้ง |
| width hook | `$C1:8456` | `$C1:9219` |
| parser | `$C1:8402` / `$C1:840F` | `$C1:91FC` |
| classifier | `$C1:84F2` | `$C1:87B3` |
| `FB` handler | `$C1:8DBA` (+ stock fb `$C1:8DF3`) | `$C1:9381` |
| loop | `$C1:83FB` | `$C1:91E3` |

**ต้องปฏิบัติกับ stale-cursor guard ตรงกันข้ามกัน**

- story engine: ต้อง *รีเฟรช* guard ไม่งั้นทุก glyph จะเริ่ม run ใหม่ ข้อความจะวาดแบบ
  ล็อกกริดหนึ่งตัวอักษรต่อหนึ่งช่อง ไม่มี VWF
- ordinary engine: ต้อง *ปล่อยไว้เฉย ๆ* ไม่งั้นป้ายที่ตั้งตำแหน่งด้วย `FD x y` ทุกป้าย
  จะถูกอ่านเป็นการต่อจากป้ายก่อนหน้า (เคยทำให้ป้าย 14 อันของหน้าต่างอาวุธวาดต่อกัน
  เป็นแถวเดียวยาวข้ามจอ)

ตัวบอกว่าใครกำลังวาดคือ width hook ทั้งสองตัว ซึ่งทำงานก่อน classifier เสมอ

## ปลายทางของการวาด

- ระบบเก่าจอง WRAM ไว้ที่ `$7E:FFA0-$FFBF` (state ของ ordinary),
  `$7E:FFC0-$FFDF` (state ของ battle) และ `$7E:FFE0-$7F:0000` (scratch)
- บัฟเฟอร์ที่เครื่องยนต์ประกอบภาพ: tilemap เงาอยู่ราว `$7E:8000`–`$7E:BFFF`
  และ tile 4bpp อยู่ `$7F:8000`–`$7F:FFFF` แล้ว DMA เข้า VRAM
- arena ของ dialogue/battle คือ `$7F:8000` → VRAM tile `$200` (วัดจาก VMADD)
  ทั้ง dialogue และ battle ใช้ที่เดียวกันทุกประการ

**direct page ไม่ใช่ scratch** — เคยเขียนทับ `$D6` ซึ่งเป็น condition register ของ
script engine ทำให้บทสนทนาค้างเป็น STP ต้องจองพื้นที่ของตัวเองใน WRAM แทน

## จอที่ไม่ได้อ่านตัวอักษรเลย

การ์ดชื่อฉากบนแผนที่ (`第２話『謎の訪問者』`) **ไม่ใช่ข้อความ** พิสูจน์แล้วด้วย
read watch คลุมทั้ง `$C0`–`$FF` ยาว 130 เฟรมตั้งแต่โหลดแผนที่จนการ์ดขึ้น: ไม่มีการ
อ่านคู่ไบต์คันจิของชื่อฉากเลยสักครั้ง และการล้าง pool ชื่อฉากทิ้งทั้งช่วงก็ไม่กระทบ
